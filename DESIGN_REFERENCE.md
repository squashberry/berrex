# BerreX design reference

BerreX uses Apple platform UI conventions as inspiration, without copying Apple assets, icons, text, or proprietary interface artwork.

## Reference screenshot research

The visual study for this first build also reviewed public screenshots/articles showing iOS 26 Liquid Glass navigation and tab-bar treatment, including Apple Music and Apple Home examples.

The code uses its own BerreX visual language: market data, charts, blue accent color, and custom iconography.

## Design rules

1. Navigation is a functional layer above content.
2. Glass effects are concentrated in important controls instead of covering every surface.
3. Large content cards stay readable and mostly solid.
4. Bottom navigation floats above scroll content with rounded corners.
5. Sheets use generous corner radii and inset spacing.
6. The interface remains useful with reduced transparency/motion settings.
7. The desktop layout expands while retaining the same visual hierarchy.

Reference screenshots were used only as visual study material; they are not included in the application bundle.
